2. PAGES
--------------------------------------------------------------------------------

  ── Home.jsx (src/pages/Home.jsx) ───────────────────────────────────────────
  The main interactive map page.

  LOCAL STATE:
    dataset       → currently selected dataset ID (e.g. 'nrega_employment_total')
    year          → selected financial year (e.g. '2020')
    selectedState → feature properties of the clicked state on map

  CHILDREN & PROP FLOW:
    <Sidebar>          dataset, setDataset, year, setYear
    <MapView>          dataset, year, onStateSelect, selectedState
    <Legend>           dataset, year
    <StateDashboard>   stateData, dataset, year, onClose, onExpand

  KEY LOGIC:
    - LULC datasets (lulc-2005/2009/2015)   → opens UseCaseReport overlay
    - MICES / NREGA datasets                 → renders choropleth on map
    - Clicking a state on map                → sets selectedState → shows StateDashboard
    - "Expand Region" in StateDashboard      → opens StateReport full page


  ── StateReport.jsx (src/pages/StateReport.jsx) ─────────────────────────────
  Full drill-down report for a selected state.

  PROPS:  stateData, dataset, year, onBack

  WHAT IT DOES:
    - Filters india_mices_districts.json for the selected state's districts
    - Calculates: total districts, max value, total volume
    - Renders top-10 districts ranked by dataset value
    - Full interactive Mapbox map zoomed to that state (district-level choropleth)
    - Hover tooltip showing district name + value

  ⚠ GAP: Top Districts list uses f.properties[dataset] (base key, not year-specific)
          Line: StateReport.jsx:239


  ── UseCaseReport.jsx (src/pages/UseCaseReport.jsx) ─────────────────────────
  Static LULC image viewer with pan + zoom interaction.

  PROPS:  datasetId, onBack

  WHAT IT DOES:
    - Displays a static image from src/image/image.png
    - Supports mouse-wheel zoom (up to 10x) and drag-to-pan
    - Export / Download buttons present (UI only — not wired to real data)
    - Triggered by dataset IDs: lulc-2005, lulc-2009, lulc-2015

  ⚠ GAP: All three LULC years show the SAME static image (image.png)

4. DATA SOURCES
--------------------------------------------------------------------------------

  ── src/data/mices/ (GeoJSON files with real boundaries + embedded data) ────

  india_mices.json
    • 36 states / Union Territories
    • Real polygon boundaries (MultiPolygon)
    • Embedded properties per feature:
        mices_dugwell, mices_shallow_tubewell, mices_medium_tubewell,
        mices_deep_tubewell, mices_total_gw_scheme,
        mices_surface_flow_scheme, mices_surface_lift_scheme,
        mices_total_sw_scheme, mices_total_water_scheme
        nrega_demand_2014 … nrega_demand_2023
        nrega_employment_total_2014 … nrega_employment_total_2023
        nrega_women_employment_2014 … nrega_women_employment_2023
        nrega_persondays_total_2014 … nrega_persondays_total_2023
        nrega_demand (base = latest year)
        nrega_employment_total (base = latest year)
        nrega_women_employment (base = latest year)
        nrega_persondays_total (base = latest year)

  india_mices_districts.json
    • ~640 districts
    • Same embedded properties as state file (NREGA + MICES per district)

  india_states.json
    • State boundaries only (NAME fields, no data)
    • NOT used in map rendering currently

  india_districts.json
    • District boundaries only (NAME fields, no data)
    • NOT used in map rendering currently

  mices_state_data.json
    • Raw water scheme counts per state (JSON object, keyed by state name)
    • NOT embedded into india_mices.json fully yet
    • Fields: dugwell, shallow_tubewell, medium_tubewell, deep_tubewell,
              total_gw_scheme, surface_flow_scheme, surface_lift_scheme,
              total_sw_scheme, total_water_scheme

  ── src/data/nrega_reports/ (CSV files — raw NREGA data) ───────────────────

  Employment - SC-ST/
    employment_scst_state.csv
      Granularity: State × Financial Year (2014-2015 to present)
      Fields: SC/ST/Others job cards issued, employment provided,
              women employment, persondays (SC/ST/Others/Total),
              families completing 100 days

    employment_scst_district.csv
      Same as above but at District level

    employment_scst_block.csv
      Block-level data
      ⚠ NEVER USED in any component

    employment_scst_panchayat.csv  [not present, only block level]

  Work Demand Pattern/

    work_demand_pattern_hh_district.csv

6. STATE & DATA FLOW
--------------------------------------------------------------------------------

  User selects Year (Sidebar year dropdown)
      │
      └─→ year state (Home.jsx)
             ├─→ MapView   uses nrega_{dataset}_{year} key in GeoJSON properties
             ├─→ Legend    computes max from nrega_{dataset}_{year} for scale
             └─→ StateDashboard reads nrega_{dataset}_{year} from stateData

  User selects Dataset (Sidebar accordion item click)
      │
      └─→ dataset state (Home.jsx)
             ├─→ MapView   switches color scale (green/orange/purple) + data key
             ├─→ Legend    switches gradient colors + recomputes labels
             └─→ StateDashboard switches displayed metric title and value

  User clicks State on Map
      │
      └─→ selectedState = { NAME_0, NAME_1, mices_*, nrega_*_YEAR, mapboxId }
             └─→ StateDashboard renders (bottom overlay)
                    ├─→ MiniMap: district-level choropleth of clicked state
                    ├─→ KPI cards with dataset values
                    ├─→ Bar chart (district distribution)
                    └─→ "Expand Region" button
                            └─→ App.handleOpenReport() called
                                    └─→ StateReport page renders (full overlay)

  User clicks LULC dataset in Sidebar
      │
      └─→ Home.setDataset(id) detects lulc- prefix
             └─→ App.onOpenUseCase(id) called
                     └─→ UseCaseReport renders (full overlay, z-50)

  User zooms map past 5.5
      │
      └─→ MapView auto-switches from State layer to District layer
             (maxzoom: 5.5 on states-fill/states-line)
             (minzoom: 5.5 on districts-fill/districts-line)

7. MAP RENDERING PIPELINE (MapView.jsx)
--------------------------------------------------------------------------------

  Mapbox GL JS initialization (once on mount):
    center: [78, 21] (India centroid)
    zoom: 4.5
    style: mapbox://styles/mapbox/streets-v12 (default)

  Sources added on first style load:
    'states'    → india_mices.json    (generateId: true)
    'districts' → india_mices_districts.json (generateId: true)

  Layers:
    states-fill     maxzoom: 5.5  fill choropleth (interpolate exponential)
    states-line     maxzoom: 5.5  black border, thickens on hover/select
    districts-fill  minzoom: 5.5  fill choropleth (interpolate exponential)
    districts-line  minzoom: 5.5  black border, thickens on hover

  Color computation:
    1. Iterates all features, reads _nrega_value (pre-computed per feature)
    2. maxStateVal / maxDistVal used as upper bound of color scale
    3. 5-step exponential interpolation: 0%, 10%, 25%, 50%, 100% of max

  Style switching (satellite / street):
    mapStyle state → triggers map.setStyle() → styleLoadedTrigger increments
    → re-runs data effect to re-add sources and layers after style reload

  Map style toggle buttons (top-right):
    🛰️  Satellite view  → mapbox://styles/mapbox/satellite-streets-v12
    🗺️  Street view     → mapbox://styles/mapbox/streets-v12

  Location search (top-center):
    Mapbox Geocoding API → fly-to on result select
